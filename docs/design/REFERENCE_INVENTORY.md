## Visual rules extracted
- Charcoal surfaces, warm white text, one restrained red. Never more than one accent on screen.
- Dot-matrix only for display numerals and wordmarks. UI text is a clean grotesk; labels are spaced mono caps.
- Shapes: perfect circles, pills, large radii. Hairline borders on dark, soft shadow on light.
- Status marker: a single small red dot before a caption.
