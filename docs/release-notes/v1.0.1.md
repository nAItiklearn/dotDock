dotDock 1.0.1 fixes what the first days of use turned up. If you have 1.0.0, it installs from inside the app
(Settings > About); otherwise download the installer or the portable exe below.

## What changed

- **Wi-Fi, Bluetooth, brightness and sound are one click away.** The dock's status area (signal, battery and time)
  opens Windows' own Quick Settings, the panel the taskbar's icons used to open.
- **The Quick settings tile shows on and off clearly**: a switched-on control is a solid disc in your theme's colour.
- Behind the scenes: the test suite now runs cleanly on Windows Server as well, and a dependency (`url`) was
  updated for a security advisory.

The files are not signed with a code-signing certificate yet, so Windows SmartScreen may warn the first time:
choose "More info", then "Run anyway". In-app updates are signed.
