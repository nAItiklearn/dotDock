dotDock 1.0.0 is the first release: a free, open-source desktop for Windows, inspired by Nothing OS. The dock,
the island, the home screen and the themes work as one desktop.

## Install

- **dotDock_1.0.0_x64-setup.exe**: the installer (for your user only, no admin rights needed).
- **dotDock_1.0.0_x64-portable.exe**: runs without installing.

The files are not signed with a code-signing certificate yet, so Windows SmartScreen may warn the first time:
choose "More info", then "Run anyway". Updates after this one install from inside the app (Settings > About) and
are signed.

## What is in it

- **The dock** takes the place of the Windows taskbar at the bottom of the screen (the taskbar is hidden, never
  removed) and hides until the pointer reaches the edge, like on a Mac. Stacks by kind, a full-screen App Library,
  magnification, live window previews, six themes including a frosted Glass, and live tiles such as system load,
  battery, quick toggles, clocks, focus timer, stopwatch, web search and voice memo.
- **The island**, a notch at the top of the screen that follows Claude Code, Codex, Copilot CLI and OpenCode:
  thinking with the token count, the file being read, the command being run, permission requests and usage limits.
- **The home screen**: widgets for the clock, date, battery, system, music, a timer, world clocks and photos, with
  an edit mode (snapping, guides, undo) and original wallpapers.
- **Themes** taken from your own wallpaper: the dock, the island and the widgets change colour together, and follow
  when you change the wallpaper.
- **Safe to try**: dotDock saves your desktop before it changes anything. Turn the theme off in Settings, or run
  the restore tool, and your wallpaper, taskbar and icons come back as they were.
